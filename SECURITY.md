# Security Policy

## Scope

This repository is a format and a set of lab exercises. It is not a
disclosure channel, not a vulnerability database, and not a list of
real findings.

## Reporting a problem in this repository

Open an issue describing the file and the problem. Do not include
real vulnerability details, real vendor names in connection with an
unfixed issue, credentials, or personal data.

## Responsible disclosure

Disclose privately to the owner first, through the owner's channel,
within the owner's agreed window. Publish only owner-approved,
redacted material, after the window. Never publish exploit detail
for an unfixed issue, and never present a lab exercise as a real
disclosure.
